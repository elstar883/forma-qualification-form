# QA-чек-лист «FORMA — анкета квалификации обращений»

## 1. Автоматическая проверка

```bash
node scripts/validate.mjs
node --check app/js/app.js
```

Скрипт проверяет структуру репозитория, разметку, стили, конфигурацию полей,
валидацию, дерево квалификации на восьми контрольных примерах, `localStorage`,
отсутствие сетевых вызовов и синтаксис всех файлов. Ожидаемый итог — строка
`OK:` с количеством полей, шагов и проверенных лидов.

CI повторяет проверку на Node.js 18, 20 и 22.

## 2. Быстрый запуск

```bash
make serve
```

Откройте <http://127.0.0.1:8080>. Проверка выполняется в Chrome или Chromium.
Дополнительно проверьте обычное открытие `app/index.html` через `file://`.

## 3. Десктоп 1440 px

- [ ] Виден текст `FORMA`, приветствие и кнопка «Начать».
- [ ] Нажатие «Начать» открывает шаг 1 с прогрессом «Шаг 1 из 6».
- [ ] Кнопка «Назад» на первом шаге неактивна.
- [ ] Нет горизонтальной прокрутки и обрезанного текста.
- [ ] Поля и кнопки не меньше 44 px по высоте.

## 4. Валидация

- [ ] Пустой шаг 1: «Дальше» не переключает шаг.
- [ ] Под именем появляется «Укажите имя — минимум 2 символа».
- [ ] Фокус стоит на поле имени.
- [ ] Контакт `abc` даёт сообщение про телефон или Telegram.
- [ ] Контакт `+7 900 000-00-00` проходит.
- [ ] Контакт `@username` проходит.
- [ ] Площадь `0`, `10001` и `70,55` не проходят.
- [ ] Площадь `70,5` проходит.
- [ ] Шаг 6 без согласия не переключается и показывает «Отметьте подтверждение,
      чтобы отправить».
- [ ] После исправления поля сообщение исчезает.

## 5. Проверка ответов и правка

- [ ] После шести шагов открывается «Проверка ответов».
- [ ] Показаны все обязательные поля и только заполненные необязательные.
- [ ] Клик по блоку «Площадь» открывает шаг 2 с текущим значением.
- [ ] После изменения и нажатия «Дальше» снова открывается проверка.
- [ ] Новое значение видно на экране проверки.
- [ ] Кнопка «Назад» на шаге, открытом из проверки, возвращает на проверку.

## 6. Отправка и карточка

- [ ] «Отправить» показывает «Спасибо, менеджер свяжется с вами».
- [ ] Черновик `forma.draft` удалён.
- [ ] Результат `forma.result` сохранён.
- [ ] «Карточка для менеджера» открывает «Карточка обращения FORMA».
- [ ] В карточке есть статус, причины и оговорка.
- [ ] Все заполненные поля показаны в формате «поле: значение».
- [ ] После перезагрузки на экране «Спасибо» карточка снова доступна.

## 8. Копирование

- [ ] «Копировать карточку» показывает «Карточка скопирована».
- [ ] В буфере есть заголовок, статус, причины, оговорка и поля.
- [ ] При недоступном Clipboard API показывается сообщение об ошибке.
- [ ] При ошибке текст карточки выделен от заголовка до последнего поля.
- [ ] В выделение не попадают кнопки и сообщение об ошибке.

## 9. Черновик

- [ ] Заполните шаг 1, перейдите на шаг 2 и перезагрузите страницу.
- [ ] Появляется «Мы сохранили ваши ответы».
- [ ] «Продолжить» открывает шаг 2 с сохранёнными значениями.
- [ ] «Начать заново» очищает черновик и возвращает приветствие.
- [ ] После отправки перезагрузка не показывает экран черновика.
- [ ] «Новая анкета» очищает оба ключа и открывает пустую форму.

## 10. Планшет 768 px

- [ ] Форма остаётся одной колонкой.
- [ ] Нет горизонтальной прокрутки.
- [ ] Кнопки и поля не меньше 44 px.
- [ ] Текст не обрезается.

## 11. Мобильный 390 и 360 px

- [ ] Приветствие, шаги, проверка, «Спасибо» и карточка помещаются по ширине.
- [ ] Нет горизонтальной прокрутки на всех экранах.
- [ ] На ширине до 480 px кнопки идут колонкой, основная — на всю ширину.
- [ ] Основная кнопка не меньше 44 px.
- [ ] Селекты и текстовые поля удобно нажимать пальцем.
- [ ] Длинные значения в карточке переносятся, а не выходят за край.

## 12. Клавиатура и доступность

- [ ] Все поля, селекты, чекбокс и кнопки доступны с клавиатуры.
- [ ] Видимый фокус у кнопок и полей.
- [ ] Блоки ответов на экране проверки — настоящие кнопки.
- [ ] Прогресс обновляется через `aria-live`.
- [ ] Сообщение о копировании объявляется через `aria-live`.
- [ ] Ошибки читаются как текст, а не только цветом.
- [ ] `prefers-reduced-motion` не требуется: анимаций нет.
