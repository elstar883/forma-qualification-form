Реализуй только указанный ниже подтверждённый этап анкеты FORMA.

Сначала прочитай `AGENTS.md`, `references/requirements.md` и относящиеся к этапу
критерии из `references/acceptance-report.md`.

Правила:

- изменяй только файлы внутри `app/`;
- не изменяй `references/`;
- не подключай внешние зависимости и сетевые запросы;
- не добавляй CRM, PDF, загрузку файлов и авторизацию;
- не переписывай уже работающие части без необходимости;
- тексты и словари меняй только в `app/js/config.js`;
- правила статуса меняй только в `app/js/qualification.js`;
- не показывай статус на клиентских экранах;
- после работы перечисли изменённые файлы;
- дай точный список ручных проверок;
- явно сообщи, что осталось на следующий этап.

Этап для реализации: $ARGUMENTS
