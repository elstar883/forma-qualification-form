## Методика

- Каждый AC отрабатывался реальным приложением в браузере (внутристраничные драйверы с настоящими обработчиками кликов, событиями `input`/`change` и реальными перезагрузками страницы), затем — статические проверки (grep) и Node-юниты.
- Скриншоты в этом окружении недоступны (нет видимого окна браузера); доказательства — протоколы прогонов выше в сессии и юнит-файлы.

## Замечания (ручные проверки до пилота)

| ID | Замечание | Причина |
|---|---|---|
| З-1 | Прогон из `file://` (двойной клик по `index.html`) | Тестовый инструмент открывает только HTTP/HTTPS. Статически проверено: относительные пути, классические `<script>`, нет модулей/CDN/запросов — препятствий нет; нужен ручной прогон |
| З-2 | NFR-01: Safari и Edge | Нет в окружении. Ручной прогон по сценариям P-1…P-5 |
| З-3 | AC-12: запись в реальный системный буфер | Окружение запрещает Clipboard API (см. AC-12\*); в обычном браузере с разрешением путь стандартный. Ручная проверка: копировать → вставить в редактор |
| З-4 | NFR-08 на `file://` | Замерить вручную (ожидание: не хуже 14 мс на localhost) |
| З-5 | OQ-1…OQ-5 из ТЗ не закрыты клиентом | Рекомендовано согласовать до пилота; на реализацию не влияют |

## Проверка границ MVP

- [x] В приложение не добавлены несогласованные интеграции (нет сервера, БД, авторизации, внешних API, PDF, CRM, AI; grep подтверждает отсутствие сетевых вызовов)
- [x] Нет реальных персональных данных и секретов (NFR-05)
- [x] Не реализован автоматический отказ клиенту (статус вычисляется лениво только в карточке менеджера; «Не наш формат» ≠ отказ — решение принимает человек; пограничные случаи → «Нужно уточнить»; отправка никогда не блокируется статусом)
- [x] Исключенные функции не маскируются незавершенными кнопками (нет ссылок на несуществующие разделы, все кнопки ведут к реализованным действиям)
