# История изменений

Формат основан на [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/),
версии следуют [семантическому версионированию](https://semver.org/lang/ru/).

## [1.0.0] — 2026-11-08

Первый публичный релиз учебного MVP.

### Добавлено

- приветственный экран, экран восстановленного черновика и шесть шагов анкеты;
- 9 обязательных и 3 необязательных поля с подсказками по формату и единицам;
- валидация имени, телефона или Telegram, площади, словарей и согласия;
- блокировка перехода и фокус на первом невалидном поле;
- экран «Проверка ответов» с переходом к нужному шагу и возвратом после правки;
- экран «Спасибо, менеджер свяжется с вами»;
- карточка менеджера со статусом, причинами и всеми заполненными полями;
- дерево квалификации BR-01…BR-14 для статусов `Приоритетная`,
  `Нужно уточнить` и `Не наш формат`;
- копирование карточки через Clipboard API и текстовый fallback;
- черновик `forma.draft` и результат `forma.result` в `localStorage`;
- адаптивная вёрстка для 1440, 768, 390 и 360 px;
- доступность с клавиатуры, `aria-live` у прогресса и сообщения о копировании.

### Документация

- README с описанием проблемы, функций, быстрого старта и скриншотов;
- ТЗ MVP, отчёт о приёмке и карта исходных материалов в `references/`;
- архитектура, модель данных, правила квалификации и QA-чек-лист в `docs/`;
- правила проекта в `AGENTS.md` и гид по участию в `CONTRIBUTING.md`.

### Проверки

- `scripts/validate.mjs` исполняет реальные модули в изолированном контексте,
  проверяет 12 полей, 6 шагов, 3 статуса, 8 контрольных лидов и хранилище;
- GitHub Actions на Node.js 18, 20 и 22;
- браузерный прогон из 52 проверок на desktop, планшете и мобильном.

### Ограничения

- приложение полностью локальное: без backend, API, CRM, PDF и сетевых
  запросов;
- данные хранятся только в браузере пользователя;
- статус — подсказка менеджеру, автоматического отказа клиенту нет.
